# Strategic Construction Group website

A static, pre-rendered website for Cloudflare Pages. No framework or runtime dependencies are required. HTML is generated by `python3 build_site.py` using the Python standard library. `styles.css` and `app.js` are shared across all pages.

## Updating projects
Edit `data/projects.json`. Each entry has a slug, title, category, location, status, description, scope, cover and ordered stages. Each stage has a name and an array of image filenames. Place photos in `assets/`, then run `python3 build_site.py`. Use verified information and remove the demonstration labels only after changing the templates to reflect verified material. Stage images currently used are generated demonstrations, not company work. There is no admin upload interface.

## Before going live with real business information
- Add verified contact details, business hours, social URLs and WhatsApp number to the shared templates in `build_site.py`.
- Have privacy and terms pages reviewed by a qualified professional.
- Replace illustrative photography and demonstration projects with authorised company images and accurate project details.
- Connect contact and quote forms to a secure backend with spam protection and a verified recipient. Currently forms validate and download a local text brief; they do not send data.
- Update the canonical base URL in `build_site.py` if a custom domain is connected, then rebuild.
- Rebuild and redeploy after changes. Cloudflare Pages is currently a direct-upload project, not connected to GitHub automatic deployment.
